# PUBG-Helper-Plugin

<div align="center">

![动态访问量](https://count.kjchmc.cn/get/@PUBG-Helper-Plugin?theme=rule34)

一个为 [Yunzai-Bot V3](https://gitee.com/Le-niao/Yunzai-Bot) 提供和平精英相关功能的插件

> 本目录为本地运行实例，在原插件基础上完成了扫码登录与主页渲染重构等增强，详见 [本地增强记录](#-本地增强记录)。

</div>

## ✨ 功能特色

- 🎨 **美观界面** - 使用 HTML 模板渲染，生成精美的数据展示图片
- 🔄 **多账号支持** - 支持绑定多个营地账号，轻松切换查询
- 📈 **数据全面** - 涵盖排位、团竞、地铁逃生、古墓模式等多种模式数据
- 🔐 **扫码登录** - 微信扫码获取营地 Token，免去手动抓包
- 🎯 **精准查询** - 支持按枪械类型筛选，精确查看特定武器数据
- ⚡ **快速响应** - 优化的 API 调用，快速获取游戏数据
- 🛠️ **易于扩展** - 模块化设计，便于添加新功能

## 📦 安装方法

1. 在 Yunzai-Bot 根目录下执行:
```bash
git clone https://gitee.com/Tloml-Starry/PUBG-Helper-Plugin.git ./plugins/PUBG-Helper-Plugin/
```

2. 重启 Bot 即可使用

> 💡 **提示：请先使用 `#绑定和平<营地ID>` 绑定你的账号，再使用其它查询指令。**

## 🎯 使用指南

### 账号管理
- `#绑定和平 [ID]` - 绑定营地ID，可绑定多个
- `#切换和平 [序号]` - 切换使用的营地ID
- `#删除和平 [序号]` - 删除绑定的营地ID
- `#我的和平ID` - 查看已绑定的营地ID列表

### 扫码登录
- `#和平QQ登录` - 生成 QQ 扫码二维码（需先 `#设置QQ 你的QQ号`），扫码后自动获取并保存 Token
- `#和平QQ登录强制` - 已有凭证时强制覆盖（QQ↔微信切换也需强制）
- `#和平QQ登录取消` - 取消当前 QQ 扫码会话
- `#设置QQ <QQ号>` - 设置/更换登录用 QQ 号
- `#和平微信登录` - 生成微信扫码二维码，扫码后自动获取并保存 Token
- `#和平微信登录强制` - 已有凭证时强制覆盖（QQ↔微信切换也需强制）
- `#和平微信登录取消` - 取消当前微信扫码会话
- `#和平登录` - 查看扫码登录教程
- `#提交和平 <Token>` - 手动提交营地 Token（抓包获取，格式 openId:gameOpenId:userId:token[:seasonId]）
- `#和平凭证` - 查看当前已保存的凭证
- `#删除和平凭证` - 删除已保存的凭证

### 资产与签到
- `#和平资产` - 查询营地仓库资产（时装/枪械/装备/载具/战备分类）
- `#和平签到` - 执行每日签到

### 地铁与排行
- `#和平地铁` - 查询地铁逃生战绩（场数/KD/单局最高收益/赛季总收益/撤离率/段位），可带赛季号：`#和平地铁15`
- `#好友排行 <数量>` - 好友段位/荣誉排行（在线优先，默认前10名）

### 数据查询
- `#和平主页` 或 `#和平主页<营地ID>` - 查看游戏信息概览
  - 支持显示经典排位、创意工坊、团竞模式、地铁逃生、古墓模式数据
  - 包含荣誉信息(最高段位、印记、队友点赞数、最近战斗时间等)

### 资讯
- `#和平资讯` - 查看资讯列表
- `#和平资讯 <编号>` - 查看对应编号的资讯详情，如 `#和平资讯 5`

### 枪械熟练度
- `#枪械熟练度` - 查看所有枪械熟练度数据
- `#枪械熟练度 <武器类型>` - 按类型筛选查看
  - 支持的类型：突击步枪、栓动狙击、轻机枪等
  - 显示使用时长、击杀数、爆头率、伤害等详细数据

### 偏好设置
- `#查看对局索引` - 查看当前默认对局索引
- `#设置对局索引 <0-12>` - 设置默认对局展示索引
- `#对局索引帮助` - 查看索引与模式对应关系

### 系统设置
- `#和平帮助` 或 `#和平插件帮助` - 显示精美帮助页面
- `#和平帮助文本` - 显示文本格式帮助
- `#和平更新` - 更新插件（仅主人）
- `#和平更新日志` - 查看更新日志（仅主人）

## ✨ 本地增强记录

以下改动为本机运行实例相对上游仓库的本地增强（未推回上游）：

- **扫码登录**：`utils/wxQrLogin.js` 实现微信扫码登录，营地客户端版本号（`cClientVersionCode` / `cClientVersionName`）从 APK 解包取真实值修正，解决"此版本已停用"报错
- **QQ 扫码登录**（`apps/qqLogin.js` + `utils/qqPageLogin.js`）：QQ 网页授权（m_authorize）+ 营地 `/user/login(qqconnect)` 换凭证，支持 `#设置QQ` 指定账号，扫码成功自动保存凭证
- **资产与签到**（`apps/assetAndSign.js` + `apps/extractCred.js`）：营地仓库分类资产查询、每日签到；签到修复 roleId 被公共参数覆盖导致 -71005 的问题
- **地铁逃生查询**（`apps/metro.js` + `resources/metro.html`）：`/play/getescaperecord` 赛季战绩（场数/KD/单局最高收益/赛季总收益/撤离率/淘汰数/幸存者段位），支持 `#和平地铁<赛季>` 查历史赛季
- **好友排行**（`apps/friendRank.js` + `resources/friendrank.html`）：`/user/friends` 好友列表 + 逐人 `/play/gethonorinfo` 荣誉，按段位星数降序、在线优先，ins 深色卡片排行
- **凭证提取模块**：配套 LSPosed 模块（com.camp.hook）抓取营地登录凭证直接复制到剪贴板（`openId:gameOpenId:userId:token`），与 `#提交和平` 格式一致，免抓包
- **指令规范**：登录指令统一为 `#和平QQ登录` / `#和平微信登录`，签到为 `#和平签到`；切换登录方式需带"强制"
- **主页渲染重构**（`resources/myHomepage.html` + `apps/myHomepage.js`）：
  - ins 深色风格，黑白灰三色主题（仅"游戏在线"状态用绿色背景）
  - 三列卡片布局：个人资料 / 印记成就 / 模式数据
  - 团竞数据拆分为排位、传统两张卡
  - 王牌 / 地铁 / 古墓印记三卡独立展示，印记图标放大并保留原始比例
  - 地铁印记卡：5 印记横排 + 历史最高财富 / 历史最高积分双成就卡
  - 区服信息以图标形式内联展示（QQ/微信、安卓/苹果），零外部依赖
  - 新增字段：最近战斗时间、在线状态、最高战力/职业、职业熟练度、最高收益成就等

## 📦 凭证提取模块（LSPosed）

> 免抓包获取营地登录凭证的 Android 模块（`com.camp.hook`），抓取成功后自动复制到剪贴板，格式与 `#提交和平` 完全一致，粘贴即用。下载见本仓库 **Releases**（`CampTokenHook.apk`）。

### 适用条件

| 环境 | 支持 | 说明 |
|---|---|---|
| root + LSPosed | ✅ 推荐 | 模块挂载到营地 APP，登录即抓取 |
| 太极（阴模式） | ⚠️ 可试 | 免 root 容器方案，营地加固版本兼容性不保证 |
| LSPatch | ❌ 不支持 | 营地是加固应用，无法重打包注入 |

### 安装步骤

1. 从 Releases 下载 `CampTokenHook.apk` 并安装
2. 打开 **LSPosed 管理器 → 模块**，勾选启用「营地凭证提取」
3. 进入模块**作用域**，勾选「腾讯和平营地」（`com.tencent.gamehelper.pg`）
4. **重启营地 APP**（建议重启一次手机确保注入生效）

### 使用说明

1. 打开营地 APP 并保持**已登录**状态（或重新登录一次）
2. 抓取成功会弹出 Toast「✅ 已复制营地凭证到剪贴板」，凭证已自动复制为：
   ```
   openId:gameOpenId:userId:token
   ```
3. 将剪贴板内容发给机器人：`#提交和平 <凭证内容>` 即完成录入
4. 录入后即可使用 `#和平主页` / `#和平资产` / `#和平签到` 等个人凭证功能

### 注意事项

- 凭证格式：`openId:gameOpenId:userId:token`（冒号分隔，无空格）
- 换账号：先切到目标账号并重新登录营地，剪贴板会自动更新为新凭证
- token 时效约 60 天，失效后重新登录营地即可重新抓取
- 无 root 设备可尝试太极（阴模式）加载本模块，把营地加进太极运行
