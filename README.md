<div align="center">

![动态访问量](https://count.kjchmc.cn/get/@PUBG-Helper-Plugin?theme=rule34)

一个为 [Yunzai-Bot V3](https://gitee.com/Le-niao/Yunzai-Bot) 提供和平精英相关功能的插件

## ✨ 功能特色

- 🎨 **美观界面** - 使用 HTML 模板渲染，生成精美的数据展示图片
- 🔄 **多账号支持** - 支持绑定多个营地账号，轻松切换查询
- 📈 **数据全面** - 涵盖排位、团竟、地铁逃生等多种模式数据
- 🎯 **精准查询** - 支持按枪械类型筛选，精确查看特定武器数据
- ⚡ **快速响应** - 优化的 API 调用，快速获取游戏数据
- 🛠️ **易于扩展** - 模块化设计，便于添加新功能

## 🌟 主要功能

- 🎮 **账号管理**
  - 绑定/切换/删除营地ID
  - 多账号管理支持
  - 账号信息展示

- 📊 **数据查询**
  - 个人主页数据概览
  - 经典排位&创意工坊(一、三称，单双四排数据总览)
  - 团竟模式数据总览
  - 地铁逃生数据总览
  - 荣誉信息查询(最高段位、王牌印记次数、队友点赞数等)

- 🔫 **枪械熟练度**
  - 查看所有枪械熟练度数据
  - 按枪械类型筛选查询
  - 显示使用时长、击杀数、爆头率等详细数据

- ⚙️ **偏好设置**
  - 设置默认对局展示索引
  - 支持13种不同模式选择

## 📦 安装方法

1. 在 Yunzai-Bot 根目录下执行:
```bash
git clone https://gitee.com/Tloml-Starry/PUBG-Helper-Plugin.git ./plugins/PUBG-Helper-Plugin/
```

2. 重启 Bot 即可使用

## 🎯 使用指南

> 💡 **提示：请先使用 `#绑定和平<营地ID>` 绑定你的账号，再使用其它查询指令。**

### 账号管理
- `#绑定和平 [ID]` - 绑定营地ID，可绑定多个
- `#切换和平 [序号]` - 切换使用的营地ID
- `#删除和平 [序号]` - 删除绑定的营地ID
- `#我的和平ID` - 查看已绑定的营地ID列表

### 数据查询
- `#和平主页` 或 `#和平主页<营地ID>` - 查看游戏信息概览
  - 支持显示经典排位、创意工坊、团竟模式、地铁逃生数据
  - 包含荣誉信息(最高段位、王牌印记次数、队友点赞数等)

### 枪械熟练度
- `#枪械熟练度` - 查看所有枪械熟练度数据
- `#枪械熟练度 <武器类型>` - 按类型筛选查看
  - 支持的类型：突击步枪、栓动狙击、轻机枪等
  - 显示使用时长、击杀数、爆头率、伤害等详细数据

### 偏好设置
- `#查看对局索引` - 查看当前默认对局索引
- `#设置对局索引 <0-12>` - 设置默认对局展示索引
- `#对局索引帮助` - 查看索引与模式对应关系

### 系统设置
- `#和平帮助` 或 `#和平插件帮助` - 显示精美帮助页面
- `#和平帮助文本` - 显示文本格式帮助
- `#和平更新` - 更新插件（仅主人）
- `#和平更新日志` - 查看更新日志（仅主人）

## 📸 功能展示

### 个人主页查询
```
#和平主页
#和平主页123456789
```
- 显示角色信息、段位进度、各模式数据统计
- 包含荣誉信息展示（最高段位、王牌印记等）

### 枪械熟练度查询
```
#枪械熟练度
#枪械熟练度 突击步枪
#枪械熟练度 栓动狙击
```
- 展示所有枪械的使用数据
- 包含使用时长、击杀数、爆头率、伤害等详细统计

### 偏好设置
```
#设置对局索引 0
#查看对局索引
#对局索引帮助
```

- 支持13种不同模式的对局数据展示设置
- 包括第三人称/第一人称、单排/双排/四排、经典/全部/创意工坊等

### 帮助页面
```
#和平帮助
#和平帮助文本
```
- 精美的HTML帮助页面，现代简约设计
- 支持文本格式备用显示
- 包含完整的功能说明和使用示例
