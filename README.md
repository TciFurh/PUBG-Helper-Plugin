## 🚀 三步上手

### 1 · 装插件

在 Yunzai-Bot **根目录**执行：

```bash
git clone https://github.com/TciFurh/PUBG-Helper-Plugin.git ./plugins/PUBG-Helper-Plugin/
```

重启 Bot，日志里出现 `和平精英插件载入中...` 即加载成功。

### 2 · 拿凭证

三选一，扫码最省事：

| 方式 | 指令 | 适合 | 备注 |
|---|---|---|---|
| **微信扫码** | `#和平微信登录` | 大多数人 | 扫完自动存 |
| **QQ 扫码** | `#设置QQ 你的QQ号` → `#和平QQ登录` | 微信不便时 | 需先设 QQ 号 |
| **手动提交** | `#提交和平 <凭证>` | 已会抓包 | 见 [抓包教程](./Tutorial.md) |
| **LSPosed 模块** | — | 安卓 root 用户 | 免抓包，见 [下文](#-凭证提取模块lsposed) |

> 💡 凭证有效期约 60 天，失效后重新扫一次即可。切换 QQ ↔ 微信登录需在指令后加 **强制**。

### 3 · 开始查

```bash
#绑定和平 123456789      # 先绑定营地 ID（可绑多个）
#和平主页                # 看看效果
```

## 🎮 指令手册

> 所有指令以 `#` 开头；`<尖括号>` 是必填参数，`[方括号]` 是可选参数。

<details open>
<summary><b>① 账号管理</b> — 绑定、切换、删除</summary>

<br>

| 指令 | 作用 |
|---|---|
| `#绑定和平 <营地ID>` | 绑定一个营地 ID，可绑多个 |
| `#切换和平 [序号]` | 切换当前使用的账号 |
| `#删除和平 [序号]` | 删除已绑定的 ID |
| `#我的和平ID` | 查看已绑定的 ID 列表 |

</details>

<details>
<summary><b>④ 每日任务</b> — 福利中心自动做任务、领奖</summary>

<br>

| 指令 | 作用 |
|---|---|
| `#和平任务` | 自动完成营地每日任务（点赞 / 分享 / 浏览 / 工具 / 充能）并领取奖励，回结果清单 |
| `#和平任务状态` | 只看两类任务（积分任务 + 福利任务）的完成情况，不做任何动作 |
| `#开启/关闭和平自动任务` | 定时自动跑的开关，默认每天 07:40，结果发给主人 |

> 点赞做完会自动撤回，不在营地留社交痕迹；「启动游戏 / 取胜一局 / 好友观战」需要真实游戏行为，做不了，会用福利任务的刷新次数换掉。
> 福利任务会**主动刷新下一轮**继续做继续领，直到当日刷新次数用尽。

## ❓ 常见问题

<details>
<summary><b>提示「未绑定营地 ID」怎么办？</b></summary>

<br>

先 `#绑定和平 <你的营地ID>`。营地 ID 在营地 APP「我的」页面可以看到，是纯数字。

</details>

<details>
<summary><b>查询报错 / 提示登录失效？</b></summary>

<br>

凭证约 60 天过期，重新 `#和平微信登录` 或 `#和平QQ登录` 即可。若之前用微信登录，现在要换 QQ，记得加「强制」。

</details>

<details>
<summary><b>扫码后一直没反应？</b></summary>

<br>

扫码会话有超时，超时后需重新发起；也确认 `#设置QQ` 里的 QQ 号是否填对。

</details>

<details>
<summary><b>地铁 / 团竞战绩是空的？</b></summary>

<br>

这两个模式查的是对应赛季的独立档案，本赛季没打过就没有数据；古墓迷途同理。

</details>

<details>
<summary><b>出图慢或者超时？</b></summary>

<br>

首次渲染要下载模板里的图标资源，之后会走缓存。VPS 上建议给足内存，puppeteer 起浏览器比较吃资源。

</details>

## 📦 凭证提取模块（LSPosed）

> 免抓包的安卓模块 `com.camp.hook`：营地登录后自动把凭证复制到剪贴板，直接粘贴给机器人。下载见仓库 **Releases**（`CampTokenHook.apk`）。

**兼容性**

| 环境 | 支持 | 说明 |
|---|---|---|
| root + LSPosed | ✅ 推荐 | 挂载到营地 APP，登录即抓取 |
| 太极（阴模式） | ⚠️ 可试 | 免 root 容器，营地加固版本兼容性不保证 |
| LSPatch | ❌ 不支持 | 营地是加固应用，无法重打包注入 |

**安装**

1. 从 Releases 下载 `CampTokenHook.apk` 并安装
2. LSPosed 管理器 → 模块 → 勾选启用「营地凭证提取」
3. 作用域勾选「腾讯和平营地」（`com.tencent.gamehelper.pg`）
4. 重启营地 APP（建议再重启一次手机，确保注入生效）

**使用**

1. 打开营地并保持已登录状态
2. 看到 Toast「✅ 已复制营地凭证到剪贴板」即成功，格式为 `openId:gameOpenId:userId:token`
3. 发给机器人：`#提交和平 <凭证内容>`

> ⚠️ 换账号要先切到目标账号重新登录营地，剪贴板才会更新为新凭证。

## 🛠 开发

```text
PUBG-Helper-Plugin/
├─ index.js              # 入口：自动加载 apps/*.js
├─ apps/                 # 指令实现（每个文件一个功能域）
│  ├─ accountManager.js  # 绑定 / 切换 / 删除
│  ├─ login.js  wxLogin.js  qqLogin.js   # 三种登录方式
│  ├─ myHomepage.js  weeklyReport.js     # 主页 / 周报
│  ├─ battleList.js  recentBattle.js     # 战绩列表 / 单局详情
│  └─ assetAndSign.js  marksmanshipSkills.js  news.js  preference.js  help.js
├─ utils/
│  ├─ api.js             # 营地 HTTP 接口封装（唯一出口）
│  ├─ battleFmt.js       # 纯格式化：数字、品质色、晋级赛、胜负文案
│  ├─ battleView.js      # 视图模型：接口结构 → 模板可直接吃的形状
│  ├─ battleCache.js     # 战绩列表缓存（编号 ↔ 详情 靠它对齐）
│  └─ storage.js  wxQrLogin.js  qqPageLogin.js  qqCampLogin.js
└─ resources/            # HTML 模板（puppeteer 渲染成图）
   └─ battlelist.html  battledetail.html  myHomepage.html ...
```

**一次查询的链路**

```text
群消息 ──▶ Yunzai 事件 ──▶ apps/xxx.js
                              │
                              ├─ utils/api.js ──▶ 营地接口(JSON)
                              ├─ utils/battleView.js  归一化（模板不判断模式）
                              └─ puppeteer.screenshot(resources/xxx.html)
                                                        │
                                                  图片 ──▶ 群
```

**设计约定**

- 模板里不写业务判断：`buildView` 把四种对局结构压成同一份视图模型，模板只判断「有没有这个区块」
- 格式化逻辑只放 `battleFmt.js`，列表与详情共用，避免两边算法漂移
- art-template 4.x 语法：`{{ each list item }}`，别写 `as`（会刷 upgrade 告警）

接口字段、踩过的坑、本地增强记录都在 **[docs/DEVELOPMENT.md](./docs/DEVELOPMENT.md)**。
